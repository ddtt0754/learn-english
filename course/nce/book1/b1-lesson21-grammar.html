🔍 Which book? 哪一本书？

新概念英语第一册 Lesson 21 · 语法精读与固定搭配分类

NCE Book 1 · Lesson 21（课本印刷页 41-42）· 3 个生词和短语 · 课文 8 句

一全文逐句语法解读

本课是「请人递书」的最短对话，语言点集中在 Which 引导的选择疑问、one 作代词替代前面的名词、This one? 这类省略句与give 的双宾结构。

¶ 1 · 提出请求与反问（句 1-3）

句子语法点
Give me a book please, Jane.双宾结构 give + 人 + 物 = give sth. to sb. · 祈使句以动词原形开头
Which book?选择疑问 Which + 名词，要求对方在有限范围内指定一个
This one?省略句 完整说法是 Do you want this one? · one 替代上文的 book，避免重复

¶ 2 · 否定与改指（句 4-5）

句子语法点
No, not that one. The red one.that one 指远处那本 · not that one 是省略的否定 · one 前可加形容词限定（the red one）
This one?对方再次确认，问句原样复现

¶ 3 · 确认与交付（句 6-8）

句子语法点
Yes, please.接受对方提供的物品时用 Yes, please.（不是 Yes, thank you.）
Here you are.把东西递给对方时的固定说法
Thank you.道谢；随意一些可说 Thanks.

二固定搭配与重点词组

短语用法与例句
Give me …, please.祈使句 + please 表示礼貌的请求。
Which + 名词?在若干同类物品中问「哪一个」；没有范围限制时用 What。
This one. / That one.one 是代词，替代前面出现过的可数名词单数；复数用 ones。
Here you are.递给东西、或请对方取用时都可以说。

三语法核心总结

Which
有限范围里选一个：Which book? —— The red one.
one
替代前面的可数名词单数，复数用 ones
this / that
this 指近处，that 指远处
请求用语
Give me … please. / Yes, please. / Here you are.
  • one 与 it：one 指「同类的另一个」，it 指「同一个」；The red one.（另一本红的）≠ It.（就是它）。
  • Yes, please. 与 Thank you.：接东西时说 Yes, please.；对方已给你、你要道谢时才说 Thank you.。
  • Which 与 What：Which 有范围（哪一本），What 无范围（什么样的书）。
