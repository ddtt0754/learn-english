NCE Book 1 · Lesson 113（课本印刷页 225-226）· 8 个生词和短语 · 课文 18 句

一全文逐句语法解读

本课围绕 坐公共汽车，重点是 none / neither 等否定表达，以及 So have I. 与 Neither can I. 的倒装结构。

¶ 1 · none 与 neither（句 8、12、14）

句子语法点
I've got none.否定 none = not any，可指人或物，可数不可数皆可
Neither can I.Neither + 助动词 + 主语，表“我也不……”（倒装）
None of our passengers can change this note.none of + 复数名词，表“没有一个……”

¶ 2 · So have I.（句 18）

句子语法点
So have I.So + 助动词 + 主语，表“我也是”（肯定倒装）
So have I.上句用 have，此处也用 have 保持一致
I haven't got any either.否定句中用 either，表“也不”

¶ 3 · 售票场景用语（句 1、3、13）

句子语法点
Fares, please!售票员用语，fare 指车费、车票
I can't change a ten-pound note.change 表“兑换（钱）”，note 指纸币
You must get off the bus.get off = 下车；get on = 上车

二固定搭配与重点词组

短语用法与例句
conductor n. 售票员本课对话人身份称谓，未在课文中作为句子成分出现。
tramp n. 流浪汉本课对话人身份称谓，未在课文中作为句子成分出现。
small change零钱。
a ten-pound note一张十英镑的钞票。
get off / get on下车 / 上车。
So have I. / Neither can I.我也……（肯定倒装）/ 我也不……（否定倒装）。

三语法核心总结

核心语法
none / neither / so 倒装
本课生词
10 个（2 个为称谓）
课文句数
18 句
重点内容
找不开的十英镑
  • none = not any，既可用于可数名词也可用于不可数名词。
  • So + 助动词 + 主语 表“我也是”；Neither + 助动词 + 主语 表“我也不”。
  • get off 表“下车”，与 get on（上车）相对。
  • 本课生词 10 个：conductor、tramp 为对话人身份称谓，已收入「固定搭配」表；其余 8 个全部嵌入课文句子，无遗漏。
