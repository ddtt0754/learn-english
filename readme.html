一这个站点包含什么？

「英语专项培优训练」是一个面向小学三年级到初中九年级的 H5 网页学习站，把单词、语法、短文跟读、新概念英语、语音基础和名师课程资源整合进同一个入口。所有页面均为单文件 HTML，无需安装软件、无强制联网依赖，打开浏览器即可使用，手机 / 平板 / 电脑通用。

从首页 index.html 进入后，可一键切换到以下六大模块：

演讲稿 · 听读说写
🎓
新概念英语

🗣️
语音基础
音标 · 拼读 · 连读 · 语调
📦

三各模块功能详解

① 单词练习

🔤
外部拼写平台

点击首页「单词练习」卡片会新窗口打开 qwertylearner.cn 画廊，作为课外单词拼写与词义巩固的强化练习，与站内短文单词表互补。

② 语法练习（grammar/）

🗺️
单元语法知识导图

knowledge_map.html 汇总 3~9 年级语法思维导图，一图掌握各年级语法体系。

✏️
中考语法每日一练

daily_practice.html 提供中考语法每日精练，循序渐进巩固考点。

📅
34 天 / 34 课系统训练

day1~day34.html 为按天递进的语法训练，lesson1~lesson34.html 为配套讲解讲义，适合长期跟练。

③ 短文练习（passage/）

🎧
逐句跟读

92 个单元跟读页（如 3a-unit1.html、7a-unit1.html、9a-unit1.html）支持逐句美式女声朗读、全文循环、同步高亮，练「听、说」。

📖
语法解读 + AI 口语测评

每个跟读页底部设有「📖 语法解读」（*-grammar.html）与「🎤 口语测评」（9a-unitN-oral-test.html）快捷入口，形成「跟读 → 语法 → 口语」训练闭环。

🖨️
打印版

print/ 目录提供单词表与演讲稿的打印友好版，可隐藏注释后直接打印成默写卷 / 讲义。

💡 短文练习模块的完整用法见 passage/readme.html（用途与使用说明）。

④ 新概念英语（nce/）

📗
经典教材导航

nce/index.html 提供第 1 册 / 第 2 册入口，按经典教材系统进阶。当前为教材导航占位，后续可继续填充课文精读与音频内容。

⑤ 语音基础（pronunciation/）

🔤
国际音标

IPA.html —— 48 个音标口诀秒记，点音标即可听发音，打牢发音底层基础。

📚
自然拼读

spelling.html —— 114 个发音规则，建立「见词能读、听音能写」的拼读能力。

🔗
连读弱读

connected.html —— 连读规则、弱读规律、自然语流，让口语更地道流畅。

🎵
五大语调

intonation.html —— 语调规则与自然节奏，掌握英语的轻重缓急。

💡 以上四个专题页均内置讲解视频弹窗（深色播放页 + 倍速 / 暂停 / 关闭控制条 + 键盘快捷键），点击卡片或播放按钮即可居中弹出观看。

⑥ 课程资源（resources/）

🎓
何凯文系统讲语法 · 12 讲

resources/index.html 罗列 12 节精讲菜单：极速背单词方法、十大词性、介词、四大类动词、16 种时态、句式与语法、特殊句式、6 种从句、语法框架、长难句拆解、口语提升等。点击任意一节即弹窗播放对应视频。

四关于首页手机号验证

🔐
首次访问验证

打开 index.html 会弹出验证卡片，需输入已登记的 11 位手机号。验证通过后写入浏览器本地存储，7 天内免登录；过期后重新弹出验证。

🔒
隐私安全

校验在本地完成：手机号经 SHA-256 哈希后与名单比对，不保存明文手机号。无网络或本地打开时，自动降级为内置哈希名单校验。

👨‍👩‍👧
仅限已登记用户

页面底部「两英豆豆教练」处悬停 / 点击可查看微信号，如有访问疑问可联系教练登记手机号。

五使用小贴士

关于朗读声音：跟读与语音页的朗读依赖浏览器语音合成（Web Speech API），推荐使用 Chrome / Edge / Safari。若首次点击没有声音，多半是语音列表尚未加载完，再点一次即可，页面已做自动重选处理。
关于离线使用：所有页面都是自包含的单文件 HTML，把整个「英语专项培优训练」文件夹拷贝到 U 盘或本地，不联网也能正常使用（仅语音朗读需要浏览器自带语音，同样离线可用）。
关于打印：在打印版页面按 Ctrl/Cmd + P，建议在打印设置里勾选「背景图形」以保留卡片底色（可选），不勾选也能得到清晰的黑白文稿。
关于视频弹窗：课程资源与语音基础模块的讲解视频会以居中弹窗播放，支持 空格 暂停、← / → 调整倍速、Esc 关闭。

六4567 学习法

关于 4567 学习法：本站全面贯彻豆豆教练独创的 4567 英语学习法（即四维五遍六天七复述），既能兼顾校内考试，又能最终实现真正听说自由。建议结合「短文跟读 → 语法解读 → 口语测评」三步闭环每日坚持。
