📖 短文听读说写训练

全学段英语学习站 · 用途与使用说明

人教版（PEP）新课标 · 小学 3~6 年级 + 初中 7~9 年级 · 92 个单元

一这个网站是做什么的？

这是一个基于 人教版（PEP）新课标英语教材 的 H5 网页学习站，把小学三年级到初中九年级共 14 个学期、92 个单元的内容，整合成一套「听、读、说、写」四维训练资源。所有页面均为单文件 HTML，无需安装任何软件、无需联网依赖，打开浏览器即可使用，手机 / 平板 / 电脑通用。

每个单元都配套两类内容：

  • 📖 课标单词表 —— 教材全部课标单词（含音标、词性、释义），支持「隐藏单词列 / 隐藏释义列」自测；
  • 🎧 跟读练习页 —— 把本单元的演讲稿 / 对话稿逐句拆开，用 美式女声 朗读，一句一句跟读练口语；
  • 🖨️ 打印版页面 —— 单词表与演讲稿的「打印友好版」，一键隐藏注释后可直接打印成默写卷 / 讲义。

内容还兼顾了 汕头 2027 中考 口语考试的情境要求，演讲稿话题贴合考纲。

二网站由哪几部分组成？

网站有两个入口，从 index.html（全学段导航主页）进入后即可互相切换：

🎧
跟读练习站（主站）
入口：index.html
92 个单元跟读页，逐句美式发音跟读、循环播放、同步高亮，练「听、说」。
🖨️
打印版（辅助站）
入口：主页顶部按钮 → print/index.html
92 个打印页（46 份单词表 + 46 份演讲稿/对话稿），可隐藏注释后打印，练「读、写」。

💡 在跟读练习站主页顶部的绿色渐变标题卡内，有一个「🖨️ 打印版 · 单词表 & 演讲稿」按钮，点击即可进入打印站。

三如何开始使用？

① 选择年级与单元

打开 index.html→ 点年级标签（三~九年级）→ 选学期（上/下册）→ 点单元卡片→ 进入跟读页
  • 年级可通过顶部标签页或下拉框双向切换，选中后下方九宫格自动显示该学期全部单元；
  • 九宫格内的单元卡片点击后变绿显示「打开中…」再跳转，手机触摸友好；
  • 需要打印版时，点主页顶部「🖨️ 打印版」按钮进入打印站，同样按年级、单元选择。

② 一个单元能看到什么？

页面类型内容核心功能
📖 单词表课标单词（音标/词性/释义）隐藏单词列、隐藏释义列，英汉互译自测
📝 演讲稿/对话稿单元主题短文或双人对话，词条全覆盖隐藏音标注释、整篇中文翻译、打印
🎧 跟读 H5逐句拆分 + 中文对照美式女声单句朗读、全文循环、同步高亮

四跟读练习页功能详解

▶️
逐句播放 / 暂停

每一句英文末尾都有「播放 / 暂停」按钮，也可直接点击句子播放；暂停后再次播放会从暂停处继续。

🔁
全文循环播放（最多 10 轮）

页面底部固定控制条：点击「▶ 全文循环播放」从第一句开始循环，最多 10 遍，控制条上方实时显示当前轮数；「■ 停止全部朗读」随时终止。

👩‍🏫
美式女声朗读（只读英文）

使用浏览器原生 Web Speech API，自动优先选择 en-US 女声（Samantha / Zira / Google US 等），零第三方依赖；每句朗读时严格只读英文，音标注释与中文绝不会被读出。

🎯
同步高亮

正在朗读的句子淡黄高亮并自动滚动居中，所在卡片的中文翻译块同步变蓝，原文 / 中文 / 单词注释一眼区分。

🙈
隐藏 / 显示音标注释

页头「隐藏音标注释」按钮一键隐藏全部红色音标词性释义小字（加粗单词保留），用于遮挡自测，再次点击恢复。

五打印版（print 站）功能详解

🖨️
打印友好设计

所有打印页都带「打印样式」：打印时自动去除背景、阴影，保留清晰的黑白文字，直接 Ctrl/Cmd + P 即可输出。

🎴
单词表双列自测

页头两个按钮：隐藏单词列（只看音标释义默写英文）、隐藏释义列（只看单词音标默写中文），可组合出不同题型。

📝
演讲稿 / 对话稿

词条加粗 + 红色音标词性释义标注，底部附整篇中文翻译；「隐藏音标注释」后可当纯净版朗读或测试材料。

🔍
词汇全覆盖校验

每个页面的橙色提示条列明本单元全部课标单词，并注明「全部嵌入、无遗漏」，方便核对。

六适合在哪些场景使用？

  • 🏫 课堂听读训练 —— 教师投屏讲解，学生逐句跟读、循环听全文；
  • 🏠 课后自主学习 —— 学生手机打开即练，先跟读再遮挡注释自测，家长无需装软件；
  • 📄 打印默写 / 讲义 —— 打印版单词表做成默写卷、演讲稿做成晨读材料；
  • 🎤 中考口语备考 —— 汕头 2027 中考口语情境演讲稿，话题与考纲贴合，适合模拟演讲；
  • 👨‍👩‍👧 亲子共学 —— 对话稿形式的双人角色跟读，适合家长与孩子分角色练习。

七使用小贴士

关于朗读声音：朗读依赖浏览器的语音合成（Web Speech API），推荐使用 Chrome / Edge / Safari。Windows 系统一般自带 Microsoft 美音女声；若首次点击没有声音，多半是语音列表还未加载完，再点一次即可，页面已做自动重选处理。
关于离线使用：所有页面都是自包含的单文件 HTML，把「短文听读说写训练-全学段」整个文件夹拷贝到 U 盘或本地，不联网也能正常使用（仅语音朗读需要浏览器自带语音，同样离线可用）。
关于打印：在打印版页面按 Ctrl/Cmd + P，建议在打印设置里勾选「背景图形」以保留卡片底色（可选），不勾选也能得到清晰的黑白文稿。
